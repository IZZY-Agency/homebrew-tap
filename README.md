# IZZY.Agency Homebrew tap

```sh
brew install --cask izzy-agency/tap/ration
```

| Cask | What it is | Source |
|---|---|---|
| `ration` | Menu-bar meter for Claude, Codex and Cursor usage limits (macOS 26+) | [IZZY-Agency/ration](https://github.com/IZZY-Agency/ration) · [ration.sh](https://ration.sh) |

`brew upgrade` picks up new releases; the cask points at the signed, notarized
`.dmg` attached to each GitHub release and pins its SHA-256.
